## **Experiment 05**
## 
### **To use OSINT tools and publicly available sources to gather And Correlate Tactical Information About An Authorized Target, Including Domain Registration Details, Historical Information, Images And Metadata, Source Code, Related Domains, Online Mentions, Rss Feeds, Ssl Certificates, Robots/Sitemap Information, Ports, And Reverse Ip Information.**

---
### Objective

Students will learn to build a structured profile of a target by investigating:
- 
- Domain and registration information
- WHOIS records
- Historical/archived information
- Website text and source code
- Subdomains and related domains
- DNS and hosting information
- IP addresses and infrastructure
- Reverse IP information
- SSL/TLS certificates
- Robots.txt and sitemap information
- RSS feeds and publicly available updates
- Mentions of the target across the Internet
- Reverse-image and publicly available image information
- EXIF/metadata where legitimately available
- Publicly exposed services and authorized port information
- Other TLDs and related online assets

### 1. WHOIS Lookup
### 
Information to collect
| Information       | Example                              |
| ----------------- | ------------------------------------ |
| Domain            | `example.com`                        |
| Registrar         | Example Registrar                    |
| Registration Date | 1995-08-14                           |
| Expiration Date   | 2027-08-13                           |
| Domain Status     | `clientTransferProhibited`           |
| Nameservers       | `ns1.example.net`, `ns2.example.net` |

### How to perform
### 
1. Open a WHOIS lookup service.
2. Enter the authorized target domain.
3. Perform the lookup.
4. Record registrar, dates, status and nameservers.
5. Save the result as evidence.


| Record | Purpose                   | Example             |
| ------ | ------------------------- | ------------------- |
| A      | IPv4 address              | `203.0.113.10`      |
| AAAA   | IPv6 address              | `2001:db8::10`      |
| MX     | Mail server               | `mail.example.com`  |
| NS     | Name server               | `ns1.example.com`   |
| TXT    | Text/security information | SPF record          |
| CNAME  | Alias                     | `www → example.com` |

### 5. Reverse IP Lookup
###### Information to collect
###### 
Determine what publicly associated domains are reported for an IP address.

How to perform
1. Obtain an IP from an authorized domain's DNS record.
2. Enter the IP into a reverse-IP lookup service.
3. Review the associated domains.
4. Record only relevant findings.

```js
IP: 203.0.113.10

Associated domains:
example.com
example.org
```
