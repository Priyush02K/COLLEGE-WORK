## Theory

### What is Website Crawling?

**Website crawling** is the automated process of visiting webpages and following links to discover other publicly accessible pages and resources.

A crawler starts from a given URL, extracts links from the webpage, visits those links, and continues the process according to the configured crawling rules.

### Simple Example

Consider an authorized website:

```text
https://example.com
```

The crawler may discover:

```text
https://example.com/
https://example.com/about
https://example.com/services
https://example.com/products
https://example.com/contact
https://example.com/news
```

The collected information can then be used to understand the structure of the website.

# Ethical and Legal Considerations

Website crawling must be performed only on a website for which the student has permission to conduct the activity.

Students must:

* Use an authorized target or a laboratory website.
* Respect the website's crawling instructions.
* Avoid bypassing authentication or access controls.
* Avoid accessing private or restricted resources.
* Avoid excessive requests that could affect website availability.
* Avoid exploiting vulnerabilities discovered during crawling.
* Stop crawling if the website owner requests it.

> **Important:** This experiment is for information gathering and website structure analysis, not vulnerability exploitation.

# Part C — Website Crawling Using Scrapy

## Step 1 — Install Scrapy

Open Command Prompt or Terminal:

```bash
py -m pip install scrapy
```

Verify installation:

```bash
py -m scrapy version
```

---

## Step 2 — Create Scrapy Project

Move to the Desktop:

```bash
cd Desktop
```

Create a project:

```bash
py -m scrapy startproject website_crawler
```

Move into the project:

```bash
cd website_crawler
```

---

## Step 3 — Create a Spider

Run:

```bash
py -m scrapy genspider site example.com
```

This creates a spider file inside:

```text
website_crawler/
└── website_crawler/
    └── spiders/
        └── site.py
```

---

# Step 4 — Configure the Spider

Open:

```text
website_crawler/spiders/site.py
```

Use the following basic crawler:

```python
import scrapy


class SiteSpider(scrapy.Spider):
    name = "site"
    allowed_domains = ["example.com"]
    start_urls = ["https://example.com"]

    def parse(self, response):

        for link in response.css("a::attr(href)").getall():

            url = response.urljoin(link)

            yield {
                "url": url
            }

            if url.startswith("https://example.com"):
                yield response.follow(url, callback=self.parse)
```

Replace `example.com` with the domain of the **authorized website**.

---

# Step 5 — Run the Crawler

Run:

```bash
py -m scrapy crawl site
```

The crawler will start from the configured URL and follow internal links.

---

# Step 6 — Save Results to CSV

To save discovered URLs:

```bash
py -m scrapy crawl site -o urls.csv
```

A file named:

```text

```

will be created.

Open the file using Excel or another spreadsheet application.

# Part F — Crawl Depth Analysis

### What is Crawl Depth?

Crawl depth indicates the number of links that must be followed from the starting page to reach a particular page.

Example:

```text
Depth 0
    |
    +--- Homepage

Depth 1
    |
    +--- About
    +--- Services
    +--- Products
    +--- Contact

Depth 2
    |
    +--- Service 1
    +--- Service 2
    +--- Product 1
    +--- Product 2
```

# Viva Questions

### Q1. What is website crawling?

Website crawling is the automated process of visiting webpages and following links to discover additional webpages and resources.

### Q2. What is the purpose of a crawler in OSINT?

A crawler helps discover publicly accessible webpages, URLs, links, and website resources systematically.

### Q3. What is an internal link?

An internal link connects one page of a website to another page within the same website/domain.

### Q4. What is `robots.txt`?

`robots.txt` is a file that provides instructions to web crawlers about which areas of a website they should or should not crawl.

### Q5. What is `sitemap.xml`?

A sitemap provides a structured list of URLs that a website makes available for discovery by search engines and other systems.

### Q6. What is Scrapy?

Scrapy is a Python framework used for web crawling and extracting structured information from websites.

### Q7. What is crawl depth?

Crawl depth represents how many link levels away a page is from the crawler's starting URL.

### Q8. What is the difference between crawling and scanning?

**Crawling** focuses on discovering webpages and resources, while **scanning** can involve probing systems or applications for technical/security information.

### Q9. Why should website crawling be authorized?

Unauthorized crawling can violate website policies, consume resources, or access information that is not intended for automated collection.

### Q10. What is the final output of this experiment?

A structured list of URLs and internal links together with a **website structure/site map** and observations about the publicly accessible website.
