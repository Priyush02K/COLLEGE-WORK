# 4. Basic Theory

## What is Infrastructure as Code?

**Infrastructure as Code (IaC)** means creating and managing cloud infrastructure using **programming/configuration files instead of manually creating resources through the cloud console**.

### Simple example

Normally:

> AWS Console → Click VPC → Click Subnet → Click EC2 → Configure → Create

With Terraform:

> Write Terraform code → Run `terraform apply` → AWS infrastructure is created

---

# 5. What is Terraform?

**Terraform** is an Infrastructure as Code tool developed by HashiCorp.

It allows us to define infrastructure using configuration files.

For example:

```text
Terraform Code
      ↓
Terraform
      ↓
AWS
      ↓
VPC + Subnet + EC2 + S3
```

# PART H — Create Provider Configuration

## Step 12: Create `provider.tf`

Open the project folder in VS Code.

Create:

```text
provider.tf
```

Add:

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 6.0"
    }
  }
}

provider "aws" {
  region = "ap-south-1"
}
```

### Explanation

```hcl
terraform {
```

Defines Terraform configuration.

```hcl
required_providers
```

Specifies the providers required by Terraform.

```hcl
hashicorp/aws
```

AWS provider maintained by HashiCorp.

```hcl
region = "ap-south-1"
```

Deploys resources in the Mumbai AWS region.

# PART I — Create Network Infrastructure

## Step 13: Create `network.tf`

Create:

```text
network.tf
```

Add:

```hcl
resource "aws_vpc" "lab_vpc" {
  cidr_block = "10.0.0.0/16"

  tags = {
    Name = "Terraform-Lab-VPC"
  }
}

resource "aws_subnet" "lab_subnet" {
  vpc_id                  = aws_vpc.lab_vpc.id
  cidr_block              = "10.0.1.0/24"
  availability_zone       = "ap-south-1a"
  map_public_ip_on_launch = true

  tags = {
    Name = "Terraform-Lab-Subnet"
  }
}

resource "aws_internet_gateway" "lab_igw" {
  vpc_id = aws_vpc.lab_vpc.id

  tags = {
    Name = "Terraform-Lab-IGW"
  }
}

resource "aws_route_table" "lab_route_table" {
  vpc_id = aws_vpc.lab_vpc.id

  route {
    cidr_block = "0.0.0.0/0"
    gateway_id = aws_internet_gateway.lab_igw.id
  }

  tags = {
    Name = "Terraform-Lab-RouteTable"
  }
}

resource "aws_route_table_association" "lab_route_association" {
  subnet_id      = aws_subnet.lab_subnet.id
  route_table_id = aws_route_table.lab_route_table.id
}
```

# 9. Understand the Network

The Terraform code creates:

```text
VPC
10.0.0.0/16
   │
   └── Subnet
       10.0.1.0/24
            │
            └── Route Table
                  │
                  └── Internet Gateway
```

### Simple meaning

**VPC**

Our AWS network.

**Subnet**

A smaller network inside the VPC.

**Internet Gateway**

Provides a path between the VPC and the Internet.

**Route Table**

Contains the rule:

```text
0.0.0.0/0 → Internet Gateway
```

This means Internet traffic is sent through the Internet Gateway.

# PART J — Create EC2 Compute Infrastructure

## Step 14: Create `compute.tf`

Create:

```text
compute.tf
```

Add:

```hcl
resource "aws_security_group" "web_sg" {
  name        = "terraform-web-sg"
  description = "Allow SSH and HTTP"
  vpc_id      = aws_vpc.lab_vpc.id

  ingress {
    description = "SSH"
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    description = "HTTP"
    from_port   = 80
    to_port     = 80
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = {
    Name = "Terraform-Web-SG"
  }
}

resource "aws_instance" "web_server" {
  ami           = "ami-0f58b397bc5c1f2e8"
  instance_type = "t3.micro"

  subnet_id = aws_subnet.lab_subnet.id

  vpc_security_group_ids = [
    aws_security_group.web_sg.id
  ]

  associate_public_ip_address = true

  tags = {
    Name = "Terraform-Web-Server"
  }
}
```

### Important

The AMI ID is **region-specific** and can become outdated.

Before running the experiment, students should verify that the AMI ID is valid for the selected AWS region and use a current compatible Linux AMI if necessary.

# 13. What is Terraform State?

Terraform uses a **state file** to keep track of infrastructure it manages.

The file:

```text
terraform.tfstate
```

contains information Terraform uses to understand the relationship between your configuration and the real infrastructure.

### Simple example

```text
Terraform Code
      ↕
terraform.tfstate
      ↕
AWS Infrastructure
```

**Do not upload `terraform.tfstate` to a public GitHub repository.**

# 20. Viva Questions

### Q1. What is Terraform?

Terraform is an Infrastructure as Code tool used to create and manage infrastructure using configuration files.

### Q2. What is Infrastructure as Code?

Infrastructure as Code is the practice of managing infrastructure using code/configuration files instead of manually configuring it.

A provider allows Terraform to communicate with a platform or service such as AWS.

A VPC is a logically isolated virtual network in AWS.

### Q9. What is EC2?

EC2 provides virtual servers/compute instances in AWS.

### Q10. What is S3?

S3 is an AWS object storage service.

### Q11. What is a Terraform state file?
