**EXPERIMENT NO. 06
DOCKER COMMANDS FOR CONTAINER MANAGEMENT**


**🐳 Step 1: Install Docker**
If you are using Windows, the easiest option is Docker Desktop.

Docker Desktop for Windows — Official Documentation

Requirements

Usually you need:

- Windows 10/11 64-bit
- WSL 2 enabled
- Virtualization enabled in BIOS/UEFI
- Docker Desktop installed

---


**Step 2: Install Docker Desktop**

- Download and install Docker Desktop.
- During installation, keep the option for:
- Use WSL 2 instead of Hyper-V
- if it is offered and suitable for your system.
- After installation, restart the computer if requested.

---


**Step 3: Start Docker Desktop**
Open:

Start Menu
   ↓
Docker Desktop

Wait until Docker Desktop shows that the Docker Engine is running.

Think of it like this:
```js

Docker Desktop
      ↓
Docker Engine
      ↓
Now Docker 
```

---


Step 4: Check Installation

Open Command Prompt or PowerShell.

Run:

docker --version

You should get something similar to:

Docker version 28.x.x

Then run:

docker info

If Docker Engine is running, you'll get information about your Docker installation.

---


**Step 5: Test Docker**

Now run:

```js
docker run hello-world
```


**Step 6: Run COMMANDS**


---

| No. | Docker Command   | Example                            | Purpose                                |
| --: | ---------------- | ---------------------------------- | -------------------------------------- |
|   1 | `docker run`     | `docker run -d --name myweb nginx` | Create and start a new container       |
|   2 | `docker ps`      | `docker ps`                        | Display running containers             |
|   3 | `docker ps -a`   | `docker ps -a`                     | Display all containers                 |
|   4 | `docker stop`    | `docker stop myweb`                | Stop a running container               |
|   5 | `docker start`   | `docker start myweb`               | Start a stopped container              |
|   6 | `docker restart` | `docker restart myweb`             | Restart a container                    |
|   7 | `docker logs`    | `docker logs myweb`                | View container logs                    |
|   8 | `docker exec`    | `docker exec -it myweb bash`       | Execute a command inside a container   |
|   9 | `docker inspect` | `docker inspect myweb`             | Display detailed container information |
|  10 | `docker rename`  | `docker rename myweb webserver`    | Rename a container                     |
|  11 | `docker pause`   | `docker pause myweb`               | Pause a running container              |
|  12 | `docker unpause` | `docker unpause myweb`             | Resume a paused container              |
|  13 | `docker kill`    | `docker kill myweb`                | Forcefully stop a container            |
|  14 | `docker rm`      | `docker rm myweb`                  | Remove a container                     |
