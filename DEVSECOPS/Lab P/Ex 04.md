# Part A — Jenkins Installation on Windows

## Experiment No. 04

### Jenkins Installation and Setup, Explore the Environment

---

## Aim

To install and configure Jenkins on a Windows operating system and verify that Jenkins is running successfully.

---

## Requirements

| Requirement | Details |
|---|---|
| Operating System | Windows 10/11 (64-bit recommended) |
| Java | Java 21 or later, as supported by the selected Jenkins release |
| Jenkins | Jenkins LTS |
| Browser | Google Chrome / Microsoft Edge / Firefox |
| Internet | Required for downloading Jenkins and plugins |

---

# Step 1: Check Java Installation

Jenkins requires Java to run.

Open **Command Prompt**:

```cmd
java -version
```

### Expected Output

You should see information similar to:

```text
java version "21.x.x"
```

If Java is not installed, install a supported Java version and then verify the installation again.

### Check Java Compiler

```cmd
javac -version
```

Example:

```text
javac 21.x.x
```

> **Note:** Always check the Jenkins LTS documentation for the Java versions supported by the Jenkins release being installed.

---

# Step 2: Download Jenkins

Open the official Jenkins website:

**https://www.jenkins.io/**

Go to the Jenkins download section and select the **LTS (Long-Term Support)** release.

For Windows, download the Windows installer (`.msi`).

Example:

```text
jenkins.msi
```

---

# Step 3: Start the Jenkins Installer

Locate the downloaded `.msi` file.

Double-click the installer:

```text
jenkins.msi
```

The Jenkins Setup Wizard will appear.

Click:

**Next**

---

# Step 4: Select Installation Folder

The installer asks for the location where Jenkins will be installed.

The default location can be used:

```text
C:\Program Files\Jenkins
```

Click:

**Next**

---

# Step 5: Configure Jenkins Service

Jenkins is installed as a **Windows Service**.

The installer asks which account should be used to run the Jenkins service.

For a laboratory installation, follow your institution's recommended service-account configuration.

> **Security Note:** Avoid running Jenkins with unnecessarily high privileges. Use a dedicated service account with only the permissions required for the laboratory tasks.

Click:

**Next**

---

# Step 6: Configure Jenkins Port

Jenkins provides a web-based interface.

The default HTTP port is:

```text
8080
```

Therefore, Jenkins can normally be accessed through:

```text
http://localhost:8080
```

The installer checks whether the selected port is available.

If port `8080` is already being used, select another available port and remember it.

Click:

**Next**

---

# Step 7: Select Java Installation

The installer asks for the Java installation location.

Select the installed supported Java directory.

For example:

```text
C:\Program Files\Java\jdk-21
```

The actual path may be different depending on the Java distribution and installation method.

Click:

**Next**

---

# Step 8: Complete Jenkins Installation

Continue through the remaining setup screens.

Click:

**Install**

Wait for the installation to complete.

When installation finishes, click:

**Finish**

Jenkins is now installed as a Windows service.

---

# Step 9: Verify Jenkins Windows Service

Press:

```text
Windows + R
```

Enter:

```text
services.msc
```

Press **Enter**.

The Windows Services window will open.

Find:

```text
Jenkins
```

Check the service status.

Expected status:

```text
Running
```

If Jenkins is stopped:

1. Right-click **Jenkins**
2. Select **Start**

---

# Step 10: Open Jenkins in the Browser

Open a web browser.

Enter:

```text
http://localhost:8080
```

If you selected a different port during installation, use that port instead.

For example:

```text
http://localhost:9090
```

The Jenkins initial setup page should appear.

---

# Step 11: Unlock Jenkins

The first time Jenkins starts, it asks for an **Initial Administrator Password**.

For the default Windows installation directory, the password is normally stored at:

```text
C:\Program Files\Jenkins\secrets\initialAdminPassword
```

Open the file using Notepad.

Copy the password.

Paste it into:

**Administrator password**

Click:

**Continue**

> **Important:** Never share the initial administrator password with other users.

---

# Step 12: Customize Jenkins

Jenkins displays two options:

### Option 1

```text
Install suggested plugins
```

### Option 2

```text
Select plugins to install
```

For this laboratory experiment, select:

**Install suggested plugins**

Jenkins will automatically install commonly used plugins.

Wait for the plugin installation to complete.

---

# Step 13: Create the First Administrator User

Jenkins will ask you to create an administrator account.

Enter your own details.

Example:

```text
Username: student_admin
Password: ********
Full Name: Your Name
Email: your-email@example.com
```

Click:

**Save and Continue**

> Use your own password. Do not use the example password shown in the manual.

---

# Step 14: Jenkins URL Configuration

Jenkins will display the Jenkins URL.

For a default local installation:

```text
http://localhost:8080/
```

Verify the URL and click:

**Save and Finish**

---

# Step 15: Start Using Jenkins

Click:

**Start using Jenkins**

The Jenkins Dashboard will now appear.

Example:

```text
Jenkins Dashboard
        |
        +-- New Item
        +-- Build Queue
        +-- Build Executor Status
        +-- Manage Jenkins
        +-- Build History
```

---

# Step 16: Verify Jenkins Installation

Open the Jenkins Dashboard and verify that:

- Jenkins Dashboard is accessible.
- The administrator account can log in.
- Jenkins is running as a Windows service.
- The Jenkins URL is accessible.
- Suggested plugins were installed.

---


## Check Java Compiler

```cmd

```

Open **Command Prompt as Administrator**:

```cmd

```

```cmd

```

```cmd

```

## Open Windows Services

```text
services.msc
```

---

# Troubleshooting

## Problem 1: `java` is not recognized

### Error

```text
'java' is not recognized as an internal or external command
```

### Solution

Install a supported Java version and configure the Java environment correctly.

Verify:

```cmd
java -version
```

---

## Problem 2: Jenkins page does not open

Try:

```text
http://localhost:8080
```

If it does not work:

1. Open `services.msc`.
2. Find **Jenkins**.
3. Check whether the service is running.
4. Start/restart the service.
5. Verify that the selected port is not being used by another application.

---

## Problem 3: Port 8080 is already in use

Open Command Prompt:

```cmd
netstat -ano | findstr :8080
```

If another application is using port 8080, either stop that application if appropriate or configure Jenkins to use another available port.

---

## Problem 4: Initial password cannot be found

Check the Jenkins installation directory.

Default location:

```text
C:\Program Files\Jenkins\secrets\initialAdminPassword
```

If Jenkins was installed in another directory, locate the Jenkins installation/data directory configured during installation.

# Part B — Jenkins Installation and Setup on Linux

## Experiment No. 04

### Jenkins Installation and Setup, Explore the Environment

---

## Aim

To install and configure Jenkins on a **Linux operating system**, verify the Jenkins service, access the Jenkins web interface, and complete the initial Jenkins setup.

---

## Requirements

| Requirement | Details |
|---|---|
| Operating System | Ubuntu/Debian Linux |
| Java | Java 21 or later, as supported by the selected Jenkins release |
| Jenkins | Jenkins LTS |
| Browser | Chrome / Firefox |
| Internet | Required |
| User Account | User with `sudo` privileges |

> **Note:** The commands below are intended for Ubuntu/Debian-based systems. Jenkins' supported Java requirements can change between releases, so verify the current Jenkins LTS requirements before installation.

---

# Step 1: Open the Terminal

Open the Linux terminal using:

```text
Ctrl + Alt + T
```

You can also open it from:

**Applications → Terminal**

---

# Step 2: Check Linux Version

Execute:

```bash
lsb_release -a
```

Example output:

```text
Distributor ID: Ubuntu
Description:    Ubuntu 24.04 LTS
Release:        24.04
Codename:       noble
```

---

# Step 3: Update the Package Repository

Update the available package information:

```bash
sudo apt update
```

Enter your Linux user password when prompted.

---

# Step 4: Upgrade Existing Packages

Execute:

```bash
sudo apt upgrade -y
```

This updates installed packages to their available versions.

---

# Step 5: Check Java Installation

Execute:

```bash
java -version
```

If Java is already installed, verify that it is a version supported by your Jenkins LTS release.

Example:

```text
openjdk version "21.x.x"
```

If Java is not installed, continue to Step 6.

---

# Step 6: Install Java

Install Java 21 runtime:

```bash
sudo apt install fontconfig openjdk-21-jre -y
```

After installation, verify:

```bash
java -version
```

Expected output will be similar to:

```text
openjdk version "21.x.x"
OpenJDK Runtime Environment
OpenJDK 64-Bit Server VM
```

---

# Step 7: Add Jenkins Repository Key

Create the keyring directory if necessary:

```bash
sudo mkdir -p /etc/apt/keyrings
```

Download the Jenkins repository signing key:

```bash
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key
```

---

# Step 8: Add Jenkins Repository

Add the Jenkins LTS repository:

```bash
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc] \
https://pkg.jenkins.io/debian-stable binary/" | \
sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null
```

---

# Step 9: Update Package Information

After adding the Jenkins repository:

```bash
sudo apt update
```

The system should now recognize the Jenkins package.

---

# Step 10: Install Jenkins

Install Jenkins:

```bash
sudo apt install jenkins -y
```

The Jenkins package will be installed and configured as a system service.

---

# Step 11: Start Jenkins

Start the Jenkins service:

```bash
sudo systemctl start jenkins
```

---

# Step 12: Enable Jenkins at System Startup

To automatically start Jenkins whenever the Linux system boots:

```bash
sudo systemctl enable jenkins
```

---

# Step 13: Check Jenkins Service Status

Execute:

```bash
sudo systemctl status jenkins
```

Expected output:

```text
● jenkins.service
     Loaded: loaded
     Active: active (running)
```

The important part is:

```text
Active: active (running)
```

Press:

```text
q
```

to exit the status screen.

---

# Step 14: Check Jenkins Port

Jenkins normally uses port:

```text
8080
```

Check whether Jenkins is listening on the port:

```bash
sudo ss -lntp | grep 8080
```

You should see a listening entry for port `8080`.

---

# Step 15: Open Jenkins in a Browser

Open a browser on the Linux machine.

Enter:

```text
http://localhost:8080
```

The Jenkins **Unlock Jenkins** page should appear.

---

# Step 16: Find the Initial Administrator Password

For a standard Debian/Ubuntu package installation, execute:

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

A long alphanumeric password will be displayed.

Example:

```text
a7f4c9e1........
```

Copy the complete password.

> **Security Note:** Do not share this password with other users.

---

# Step 17: Unlock Jenkins

Return to the browser.

On the **Unlock Jenkins** page:

1. Paste the initial administrator password.
2. Click **Continue**.

---

# Step 18: Customize Jenkins

Jenkins will display:

```text
Customize Jenkins
```

Two options are generally available:

### Option 1

```text
Install suggested plugins
```

### Option 2

```text
Select plugins to install
```

For this experiment select:

**Install suggested plugins**

Wait for Jenkins to download and install the plugins.

---

# Step 19: Create Administrator Account

Create your own Jenkins administrator account.

Example:

```text
Username: student_admin
Password: ********
Full Name: Your Name
Email: your-email@example.com
```

Click:

**Save and Continue**

> Do not use the example username/password for an actual installation.

---

# Step 20: Configure Jenkins URL

Jenkins displays the Jenkins URL.

For a local installation:

```text
http://localhost:8080/
```

Verify the URL.

Click:

**Save and Finish**

---

# Step 21: Start Using Jenkins

Click:

**Start using Jenkins**

The Jenkins Dashboard should now appear.

---

# Step 22: Verify Jenkins Installation

Run:

```bash
sudo systemctl status jenkins
```

Confirm:

```text
Active: active (running)
```

Then open:

```text
http://localhost:8080
```

The Jenkins Dashboard should be accessible.

---

# Step 23: Explore Jenkins Home Directory

Jenkins stores its important data in the Jenkins home directory.

For a standard Linux package installation:

```text
/var/lib/jenkins
```

Check the directory:

```bash
sudo ls -la /var/lib/jenkins
```

You will find Jenkins-related files and directories.

---

# Step 24: Explore Jenkins Configuration

The Jenkins service configuration can be examined using:

```bash
systemctl cat jenkins
```

This helps students understand how Jenkins is managed by **systemd**.

---

# Step 25: View Jenkins Logs

To view Jenkins service logs:

```bash
sudo journalctl -u jenkins
```

To view recent logs:

```bash
sudo journalctl -u jenkins -n 50
```

To continuously monitor logs:

```bash
sudo journalctl -u jenkins -f
```

Press:

```text
Ctrl + C
```

to stop viewing logs.

---

# Step 26: Stop Jenkins

To stop the Jenkins service:

```bash
sudo systemctl stop jenkins
```

Check:

```bash
sudo systemctl status jenkins
```

The service should no longer show:

```text
active (running)
```

---

# Step 27: Start Jenkins Again

Start the service:

```bash
sudo systemctl start jenkins
```

Verify:

```bash
sudo systemctl status jenkins
```

Expected:

```text
Active: active (running)
```

---

# Step 28: Restart Jenkins

Jenkins can be restarted using:

```bash
sudo systemctl restart jenkins
```

Then verify:

```bash
sudo systemctl status jenkins
```

---

# Important Linux Jenkins Commands

| Command | Purpose |
|---|---|
| `sudo systemctl start jenkins` | Start Jenkins |
| `sudo systemctl stop jenkins` | Stop Jenkins |
| `sudo systemctl restart jenkins` | Restart Jenkins |
| `sudo systemctl status jenkins` | Check Jenkins status |
| `sudo systemctl enable jenkins` | Start Jenkins automatically at boot |
| `sudo systemctl disable jenkins` | Disable automatic startup |
| `sudo journalctl -u jenkins` | View Jenkins logs |
| `sudo ss -lntp \| grep 8080` | Check Jenkins port |
| `sudo cat /var/lib/jenkins/secrets/initialAdminPassword` | Display initial password |
| `sudo ls -la /var/lib/jenkins` | Explore Jenkins home directory |

# Troubleshooting

## Problem 1: Java Not Found

### Error

```text
java: command not found
```

### Solution

Install Java:

```bash
sudo apt install fontconfig openjdk-21-jre -y
```

Verify:

```bash
java -version
```

---

## Problem 2: Jenkins Service Not Running

Check:

```bash
sudo systemctl status jenkins
```

Restart:

```bash
sudo systemctl restart jenkins
```

If the problem continues, check the logs:

```bash
sudo journalctl -u jenkins -n 100
```

---

## Problem 3: Jenkins Web Page Does Not Open

Check the service:

```bash
sudo systemctl status jenkins
```

Check port:

```bash
sudo ss -lntp | grep 8080
```

If Jenkins is not listening on port 8080, inspect the Jenkins service logs.

---

## Problem 4: Firewall Blocking Port 8080

If Ubuntu's firewall is enabled, check:

```bash
sudo ufw status
```

If Jenkins needs to be accessed from another machine and your lab network policy permits it, allow port 8080:

```bash
sudo ufw allow 8080/tcp
```

Then verify:

```bash
sudo ufw status
```

> **Security Note:** Do not expose Jenkins directly to the public Internet just to make it accessible. In a real deployment, Jenkins should be protected with appropriate network controls, authentication, HTTPS, and access restrictions.
