# Ex.01: Write Code for a Simple User Registration Form for an Event Using Flask

## Procedure

### Step 1: Install Flask

Open **Terminal** or **Command Prompt**.

Install Flask:

```bash
pip install flask
```

Verify the installation:

```bash
python -m flask --version
```

---

### Step 2: Create Project Folder

Create a project folder named:

```
EventRegistration
```

Inside the folder, create:

- `app.py`

Create another folder named:

- `templates`

Inside the `templates` folder, create:

- `index.html`
- `success.html`

---

### Step 3: Create Flask Application

Create the Flask application in:

- `app.py`

---

### Step 4: Create Registration Form

Create the registration form in:

- `templates/index.html`

---

### Step 5: Create Success Page

Create the success page in:

- `templates/success.html`

---

### Step 6: Run the Application

Open **Terminal** or **Command Prompt**.

Run the application:

```bash
python app.py
```

---

## Output

```
Running on http://127.0.0.1:5000/
```
