Experiment 9
Title

Implement Threat Modeling Using Threat Dragon

Aim

To implement threat modeling using Threat Dragon by creating a Data Flow Diagram (DFD) and identifying potential security threats in a web application.

Software Requirements
Threat Dragon (Desktop or Web Version)
Windows/Linux/macOS
Web Browser (for the online version)
Theory

Threat modeling is a structured approach to identifying, analyzing, and mitigating potential security threats in an application before deployment.

Threat Dragon is an open-source threat modeling tool developed by OWASP. It helps developers create Data Flow Diagrams (DFDs) and automatically identifies security threats based on the STRIDE model.

The STRIDE model includes:

S – Spoofing
T – Tampering
R – Repudiation
I – Information Disclosure
D – Denial of Service
E – Elevation of Privilege
